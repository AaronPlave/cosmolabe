# Issue #297 acceptance matrix

This maps the issue body, its October 30–31 amendments and PR #334 review to
one implementation. A check means the operation and named acceptance exist;
CI/physical-browser results are recorded separately in `README.md` and
`acceptance.json`. Paths below are relative to the repository root. “Shared”
means UI, typed host and generated script operations use the same domain action;
agent mutations additionally require the host's effect policy. Read operations
use the typed port and bounded discovery tools rather than printing data as
script statements.

## Confirmed defects and repairs

- **Scientific source coverage:** sampled trajectories now return unavailable
  outside their evaluable intervals, including gaps between declared OEM
  segments. OEM START/STOP and USEABLE_START/STOP intersect actual records;
  no cadence threshold invents gaps. Common world-position and object-state
  reads, dependent bodies and native timeline profiles share this boundary.
  Endpoint holding is an explicit display-only path, including composite
  children. Invalid OEM imports also remain unavailable instead of becoming
  zero-position scientific samples. Different segment frames/centers/time
  systems are rejected; this is not a general multi-frame OEM assembler.
- **Imagery evidence:** the safe projection retains acquisition/requested dates,
  date policy, pending state, range and baked illumination, alongside separate
  request outcome and current-view drawing/coverage observations. Missing
  drawing observations stay unknown; selecting another day does not establish
  different pixels, weather or a drawn daily product. Only exact reviewed
  built-in Earth attribution strings are public; endpoints and unapproved
  identities remain withheld. Answer checking uses published imagery evidence
  to catch unsupported drawing/appearance claims. This bounded language check
  is not a general verifier of arbitrary natural-language claims.
- **Comparisons:** history guidance keeps range and signed range-rate on the
  existing timeline. Profile responses no longer require every investigation
  to become a minimum report. Compute-only approach searches verify their saved
  native results without accumulating false camera warnings. Presenting a
  computed result pauses, seeks and frames its actual target, expands the
  existing timeline and fits its search interval, retaining both query lanes.
- **Answer checking:** speeds are not distances; “km/s” and “kilometers per
  second” no longer trigger false range contradictions. Missing samples must
  be disclosed, while digit, spelled-count and fraction wording are accepted.
  Published gap timestamps remain usable evidence even though their values
  are null. A safe replacement answer for paired range/range-rate evidence
  retains the sampled closing/opening comparison and gaps instead of reporting
  only a minimum. It summarizes existing native samples; it runs no solver.
- **Unsupported science:** operation guidance separates visual spacecraft/ring
  art from physical hull/particle contact authority and unavailable algorithms.
  It does not promise that loading a mesh creates contact, wind or ice science.
  Kernel reads do not silently acquire a predicted/observed classification:
  unknown source classification remains unknown.

The CCSDS MGS fixture is a three-record excerpt before its declared usable
interval. Ingest tests explicitly bound that excerpt to its actual records;
separate tests refuse the original nonoverlapping usable interval. They do not
remove usable-bound checks to preserve the old zero/held-position behavior.

## Composer guidance and comprehension

“What can I do here?” is now in the existing Ask composer. Opening it uses local
registry/scene reads only. Catalog camera presets, configured imagery and
selected-object/parent position availability supply up to five examples. A
camera's default tracked pair does not become a suggested investigation.
Choosing an example fills and focuses the editable prompt; it neither submits
nor navigates. Selection/catalog changes dismiss stale examples. No examples
are generated by a model and no catalog-specific prompt list is shipped.

In one task-based **developer walkthrough**, the person correctly reported that
choosing an example prefilled a prompt. They found “Authored view · resulting
visibility unverified” understandable as a developer but vague for an end user.
The revised label is “Preset camera view; no event calculated. Objects may be
small or hidden.” The distance example now says that some dates may lack data
and that it does not measure distance to a surface. Four loaded-catalog tests
confirm fill-only behavior after that copy change. This is a comprehension-led
copy iteration, not an independent first-time-user study or a success guarantee.

## Matched model comparison and limits

The same original OEM and Clipper prompts were run with Haiku and Sonnet,
identical catalogs/tool schemas/output limits, and no fallback. Cache warmth
was uncontrolled; final cells overlapped in wall time. Earlier diagnostic runs
exposed common tool/answer-check defects in both models, so the evidence did
not support an architectural planner rewrite. Sonnet also makes factual and
composition mistakes: a stronger model is not a factual authority or a reason
to change production routing. Final per-model outcomes are in the evidence.

The OEM native plots expose closing/opening and real end gaps. A missing or
contradictory model explanation can still be replaced by the existing host's
factual account; that is explicitly labeled in Ask. Clipper comparisons retain
both native query lanes and present the closer Europa result; a distant
Ganymede range minimum is not renamed a flyby. Point-state sampling independent
of Event Finder checks the three ranges. It establishes agreement with loaded
ephemerides, not external source accuracy or certified global completeness.

The final runtime revision is `d198eb7ac30b2e23608f023718de39399439beda`;
subsequent changes contain validation documentation and a coverage-sensitive
fixture test only. The evidence records a production-source fingerprint.
Final Haiku calls all ended with `done`; that is a transport outcome, not a
claim that every requested visual or explanation passed. OEM needed truthful
host replacement in both final models; Clipper's presentation was verified in
both. Production routing remains unchanged. The benchmark’s selected-query completion
observation now uses that query’s result page, rather than whichever query is
active in the editor; earlier raw captures can show `searchComplete:false`
while a different completed query is selected. Final native event predicates
and model-visible computed results establish the reported presentation.

Final Haiku cells used 998,191 raw processed tokens for an estimated $0.029039;
the two final Sonnet cells used 241,790 for $0.139140. Haiku elapsed p50 was
10.938 s and p95 21.551 s. All 46 review cells, including diagnostic reruns,
cost $0.628523 estimated; adding the earlier assessment gives **$0.665130**
against the approved **$2** total. These are API-usage estimates, not billing.
The independent Clipper ranges agree within 0.000001 km and 0.05 s; this is
bounded numerical agreement, not ephemeris accuracy.

Local checks: 1,385 package/benchmark tests and 857 viewer tests passed; package
build, test/viewer/Svelte typechecks, full lint, purity lint and diff checks
passed. The four-catalog local browser harness verifies fill-only examples,
real OEM boundaries and Stop. CI additionally exposed a Cosmographia Voyager
test that relied on a hard-coded epoch outside the downloaded file; it now
asserts covered interpolation and explicit refusal before the first record.
Final CI status is recorded in the PR rather than frozen as a timeless claim.

Node). The paid harness is plan-only unless explicitly enabled. Retain an
aggregate cost cap across invocations rather than treating each sub-cap as a
new authorization.

Local validation uses Chromium software WebGL. Physical GPU rendering and
cancellation of every possible native solver/camera race are not established.

proposed mutation, and verifies that clock, full pose and selection remain
unchanged. It spends no provider tokens and makes no billing claim about
cancelled live requests.

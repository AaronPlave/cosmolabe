# Ask benchmark, 2026-11-01

The thirteen-task paired comparison supports keeping fixed tools as the default.
Haiku is materially cheaper in these runs, but neither model/mode has complete
factual acceptance across this small suite. Do not infer general equivalence,
change model defaults or route commands from this exploratory result.

## Quality comes before cost

Each row covers the same thirteen tasks with one fresh scene/conversation per task:
the original twelve-task matrix plus the corrected missing-viewpoint case. The
extra instrumented Flight 12 runs and invalid airfield probes are excluded from
these combined tables.
“Both” requires passing independent state checks and a agent-reviewed factual
answer. Correct unavailability refusals and the expected forced cancellation
count as accepted outcomes; they do not mean the original requested mutation
completed. A partial answer never counts as fully verified.

| Model | Tools | State checks | Factual pass / partial / fail | Both |
|---|---|---:|---:|---:|
| Sonnet 5.5 | Fixed | 12/13 | 10 / 2 / 1 | 10/13 |
| Sonnet 5.5 | Discovery | 12/13 | 11 / 2 / 0 | 11/13 |
| Haiku 5.5 | Fixed | 13/13 | 11 / 2 / 0 | 11/13 |
| Haiku 5.5 | Discovery | 12/13 | 8 / 4 / 1 | 8/13 |

The relative “next flight” task has a rubric limitation: the current clock can be
an implicit anchor even without a selected activity. Three modes changed the
selection and failed the deliberately conservative unchanged-state expectation.
All four answers were marked partial for incomplete navigation/verification or
anchor ambiguity. These cells alone do not establish a general relative-flight
navigation regression. A separate unresolved viewpoint-reference test follows below.

All four modes reached Flight 12 at its paused estimated start, with independent
camera projection/size checks confirming actual framing. All four also omitted
full imagery attributions and degraded-tile caveats in that mixed workflow.
Dedicated Mars-inventory prompts improved quality: both Sonnet modes and fixed
Haiku reported all attributions and observed degraded/missing tile counts;
discovery Haiku omitted the degraded-tile caveat.

Both models reached the exact synthetic MoonFall PSR waypoint and identified it
as demo content. Sonnet fixed nevertheless changed longitude -2° to “2°E” in the
answer. Haiku discovery inferred that a large longitude difference meant the
site was not close to Shackleton near the south pole. The catalog anchors are
(-2°, -89.71°) and (129.78°, -89.67°), respectively; on the catalog's 1737.4 km
reference sphere their separation is about 17.17 km. This is an anchor-to-anchor
spherical check in the catalog's MOON_ME_DE421 frame, not a crater-boundary or
terrain-distance measurement. Viewer-state success did not prevent these factual
errors. The other two MoonFall answers passed the factual rubric.

All four modes preserved unknown full-view coverage and withheld attribution in
the dedicated lunar provenance task. All correctly refused the unavailable
persistent measurement/annotation without changing the observed scene. All four
cancel tests stopped after a completed mutation at the next HTTP boundary, kept
already-applied changes, and showed no later mutation. This tests a specific
cancellation boundary, not every in-flight/network/manual-takeover race.

## Efficiency investigation

The fixed catalog initially serialized to 13,368 schema characters, versus 2,500
for discovery. Discovery still increased total requests, raw tokens, elapsed time
and estimated cost for both models in this matrix. Smaller starting schemas did
not imply lower total work.

In the original twelve-task matrix, Sonnet discovery described 44 capability IDs with no repeated descriptions within
a task. Haiku discovery described 43 IDs with one repeat. Models already batch
multiple schema descriptions; repeated discovery is not the dominant explanation
for these totals. Scene reads were 21/21 for Sonnet fixed/discovery and 22/24 for
Haiku. Some read repetition is essential post-write verification. Oversized scene
reads that return no usable state should be fixed before simply removing reads.

The agent loop's default serialized result budget is 6,000 characters
(`packages/control/src/agent-loop.ts`). An initial Ingenuity scene observation is
about 6,200 compact JSON characters even before receipt overhead, because it includes both
surface and imagery inventories. Models explicitly reported `result-too-large`.
Retained public observations come from the tool event before serialization;
their presence in the artifact does not prove the model received that payload.

A future general compaction should keep compact scene/time/selection facts
available and leave detailed datasets to targeted reads. Preserve source
attribution, unknown coverage, degraded tile counts and partial receipts in those
reads. Do not prefix-truncate JSON, discard scientific uncertainty, remove
post-write checks or raise budgets without measuring the resulting total work.
No model-facing compaction or runtime concurrency change was made in this PR.

The initial matrix does not retain response-level call grouping. Its requests and
step counts can identify multi-call opportunities, but cannot prove which reads
were batched. Supplementary instrumentation records semantic call names per model
response and serialized result codes, without provider text/reasoning. Execution
remains sequential even when independent reads are emitted together. Do not
parallelize mutations or retry partly completed writes to improve these numbers.

## Instrumented follow-up

[Supplementary observations and reviews](2026-11-01-supplement.json) retain four
fresh Flight 12 runs and four excluded setup probes. Flight 12 again passed all
independent state checks, while all four answers remained partial for missing
layer attributions/degraded-tile caveats.

|---|---|---:|---:|---:|---:|
| Sonnet 5.5 | Fixed | 5 | 54,923 | $0.027418 | 1 |
| Sonnet 5.5 | Discovery | 9 | 99,556 | $0.064731 | 1 |
| Haiku 5.5 | Fixed | 6 | 62,621 | $0.001912 | 1 |
| Haiku 5.5 | Discovery | 13 | 165,612 | $0.004730 | 2 |

Sonnet fixed emitted `describeScene`, `listActivities`, `getImagery` and
`getSurfaceData` together in its first response. Haiku fixed grouped
`getSurfaceData` and `getImagery` with selection/seek calls in one response.
Sonnet discovery grouped domain searches and later grouped framing with targeted
surface reads. These are model-response groups: the agent executed the calls
sequentially with its existing ownership/cancellation guards. Read batching is
already possible without a new runtime scheduler. Haiku discovery repeated the
scene read before any mutation and received the same output-budget omission;
this is a concrete candidate for avoiding redundant reads without deleting the
necessary final post-write read. Described IDs were batched and reused.

The airfield setup probes are explicitly **excluded**. The loaded Ingenuity
catalog has just one name containing “Airfield” (Airfield B), so the prompt “that
airfield” does not supply two competing named candidates. Resolving that unique
match is legitimate. The conservative unchanged-state check remains visible as
false in the evidence, but must not be interpreted as a model failure. This
invalid probe prompted the corrected missing-viewpoint-reference case in source
`ff4517a9`. Excluded probes do not count as factual successes or failures.

## Corrected ambiguity acceptance

[Four unresolved-viewpoint runs](2026-11-01-ambiguity.json), source `ff4517a9`,
all passed both unchanged-state and factual review. With the prompt “Show that
viewpoint” and a fresh conversation, all four modes asked which of the real
Earth Close, Lunar Orbit or Default viewpoints was intended. None changed the
camera, clock, selection or tracking. Each used two model requests; combined
usage was 42,517 raw processed tokens and $0.008046 estimated. These four cells
complete the thirteen-task comparison above. They establish this specific
missing-reference behavior, not broad ambiguity-handling equivalence.

The reported factual reviews are by one Codex agent against the retained public
observations and independent probes. They are neither blinded nor multiple-human
ratings; detailed reasons and exact-evidence digests remain in each artifact.
